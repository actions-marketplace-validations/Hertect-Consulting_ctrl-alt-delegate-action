# Copy rules

Word rules for anything Ctrl Alt Delegate says in public: README, `action.yml`, the Marketplace listing, the PR comment. This is the file `docs/BUILD_BRIEF.md` means by "word rules." If a chat instruction changes something here, update this file in the same PR — per `docs/process/BUILD_RULES.md` rule 9, nothing in a chat window overrides it otherwise.

## Name

Full name first: "Ctrl Alt Delegate." "CAD" is fine after that, in the same document.

## Banned words

- "manual" — say "instruction files" instead.
- Filler that adds no information: "simply," "just," "seamless," "powerful," "robust," "leverage."

## Required term

"Instruction files" is the name for the whole category: AGENTS.md, CLAUDE.md, the Copilot instructions file, Cursor rules, GEMINI.md, SKILL.md files. Not "config," "docs," or "rules files."

## Approved copy

- Marketplace name: Ctrl Alt Delegate
- Marketplace description: Checks the instruction files your AI coding agents follow and fails the pull request when they're wrong. Free for any repo.
- Workflow usage: `uses: Hertect-Consulting/ctrl-alt-delegate-action@v1`
- Footer tagline, last line of every PR comment, exact: "Receipts for one repo. Ctrl Alt Delegate keeps them for all of yours." Links to hertect.com/ctrl-alt-delegate.

## Style

Plain language. Lead with the reader's problem, not the product name. Short sentences. No more words than it takes.
