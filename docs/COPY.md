# Copy rules

Word rules for anything Ctrl Alt Delegate says in public: README, `action.yml`, the Marketplace listing, the PR comment. This is the file `docs/BUILD_BRIEF.md` means by "word rules." If a chat instruction changes something here, update this file in the same PR — per `docs/process/BUILD_RULES.md` rule 9, nothing in a chat window overrides it otherwise.

## Name

Full name first: "Ctrl Alt Delegate." "CAD" is fine after that, in the same document.

## Banned words

- "manual" — say "rules and skills" instead.
- Filler that adds no information: "simply," "just," "seamless," "powerful," "robust," "leverage."

## Required term

"Rules and skills" is the name for what these files contain and what Ctrl Alt Delegate checks: the What/Applies to/Check items inside AGENTS.md, CLAUDE.md, the Copilot instructions file, Cursor rules, and GEMINI.md, plus each SKILL.md as one skill. Never call this category "instruction files" or "instructions" alone, especially in a heading. Not "config" or "docs" either.

## Approved copy

- Marketplace name: Ctrl Alt Delegate
- Marketplace description: Checks the rules and skills your AI coding agents follow and fails the pull request when they're wrong. Free for any repo.
- Workflow usage: `uses: Hertect-Consulting/ctrl-alt-delegate-action@v1`
- Footer tagline, last line of every PR comment, exact: "Receipts for one repo. Ctrl Alt Delegate keeps them for all of yours." Links to hertect.com/ctrl-alt-delegate. "Keeps the receipts" appears nowhere else in this repo's public copy — the README's own last line is this same tagline, and that is the only other place it belongs.
- Status label, if one is ever surfaced in copy: "Flagged."

## Current tagline

Headline: "Your AI tools know your version. Ctrl Alt Delegate knows everyone's."

Subline: "Every rule, skill, AI tool, and codebase. Where it lives. What it touches. Who owns it. What changed since anyone last checked it."

Used atop the README, under the wordmark. "Delegate" is magenta on hertect.com; Markdown can't color part of a line, so the README keeps the name plain.

## Style

Plain language. Lead with the reader's problem, not the product name. Short sentences. No more words than it takes.
